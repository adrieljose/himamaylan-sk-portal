# 🗳️ Himamaylan City COMELEC — 2026 SK Age & Eligibility Checker

A civic-technology web application built for the **Himamaylan City COMELEC / Office of the Election Officer**, designed to assist youth voters and aspiring candidates across all 19 barangays of Himamaylan City, Negros Occidental for the **November 2, 2026 Barangay and Sangguniang Kabataan Elections (BSKE)**.

---

## 🌟 Key Features

- **Exact Age Engine:** Calculates exact years, months, and days lived as of **November 2, 2026**.
- **Dual Eligibility Check:** Evaluates both **SK Voter (15–30)** and **SK Candidate (18–24)** statutory qualification thresholds under Republic Act No. 10742 and RA 11768.
- **Visual Spectrum Timeline:** Color-coded age timeline highlighting the user's computed status across statutory tiers.
- **Contextual Civic Guidance:** Provides tailored guidance for 14-and-under, 15–17 youth voters, 18–24 candidates/voters, 25–30 voters, and 31+ regular voters.
- **Interactive Self-Assessment:** 6-question Yes/No check for citizenship, 1-year residency, literacy, registration, and anti-political dynasty rules.
- **19 Himamaylan Barangays Directory:** Real-time search and filter across Poblacion, Coastal, Rural, and Upland districts.
- **Official Print Slip:** Print layout (`window.print()`) with official COMELEC headers, breakdown, and statutory notices.
- **Web Share & Clipboard Copy:** Native mobile sharing without transmitting private birthdate data.
- **100% Client-Side Privacy:** Zero server storage, no database, no advertising cookies, fully compliant with RA 10173 (Data Privacy Act of 2012).

1. **Republic Act No. 10742** — *Sangguniang Kabataan Reform Act of 2015*
2. **Republic Act No. 11768** — *Amendments to the SK Reform Act*

4. **COMELEC Official Resolutions** — *Synchronized 2026 BSKE Guidelines*

## 🚀 Getting Started Locally

### 1. Clone & Install Dependencies
```bash
git clone <repo-url>
cd "HIMAMAYLAN SK WEBSITE"
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

---

## 🌐 Deploying to Vercel

1. Push your repository to GitHub or GitLab.
2. Import the repository in [Vercel](https://vercel.com/new).
3. Set the Framework Preset to **Next.js**.
4. Leave build settings as default (`npm run build`).
5. Click **Deploy**.
